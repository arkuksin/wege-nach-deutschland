# Wege nach Deutschland · Пути в Германию

A public German/Russian guide to university studies and initial nursing vocational training in Germany, with official sources, institutional contacts, a document checklist and anonymous email templates.

Information reviewed on **27 October 2026**. This is general orientation; institutions and authorities decide individual cases. Recheck time-sensitive requirements before applying.

## Local preview

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Open `http://127.0.0.1:4173/`. No build or installation is needed.

```sh
npm run check
```

## Publication

GitHub Pages: publish the `main` branch root, with `.nojekyll`. Only this isolated project directory belongs in the public repository.

- `?lang=de` / `?lang=ru`: interface language.
- `?route=care` / `?route=study`: selected education route.
- No backend, analytics, external fonts, registration or persistent browser storage.
- Email buttons prepare text or open a mail client; they do not send messages.
- Checklist state is held only in memory.

Do not add personal documents, names, credentials or private correspondence. The official public institutional sources are linked directly from the guide.
