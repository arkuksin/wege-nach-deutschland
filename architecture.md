# Architecture

Public bilingual information guide, deployed on GitHub Pages.

- Buildless HTML, CSS and JavaScript ES modules, with no server or third-party runtime.
- German and Russian content in `content.mjs`; language is reflected in `?lang=de` or `?lang=ru`.
- No accounts, analytics, external fonts, persistent visitor storage or submitted forms.
- Anonymous inquiry templates; only official public institutional contact addresses.
- Only the files in this dedicated directory belong to the public repository. No documents from its parent directory are included.
- GitHub Pages serves the `main` branch root. All asset URLs are relative for project-page compatibility.
- Verify content structure, both languages, keyboard-accessible controls, responsive layout and deployed HTTP response.
